# VGA Interactive Shape Controller

## Overview
This project implements an interactive VGA graphics controller using Verilog/VHDL.

The FPGA/Zynq board was connected to a monitor through the VGA interface.  
The design generates video signals and displays graphical shapes on the screen.  
Different push buttons were used to control the position, size, and orientation of the shapes in real time.

## Features
- VGA signal generation
- Displaying a rectangle on the monitor
- Moving the rectangle up and down using push buttons
- Optional/bonus horizontal movement control
- Rotating the rectangle 90 degrees to the right or left using buttons
- Drawing a circle on the VGA display
- Moving the circle up and down using buttons
- Increasing and decreasing the circle size
- Minimum and maximum size limits for the circle
- Real-time hardware testing on FPGA/Zynq board

## Tools and Hardware
- Verilog / VHDL
- Xilinx Vivado
- FPGA / Zynq Development Board
- VGA Monitor
- Push Buttons
- Board-level testing

## Results
The design was simulated, synthesized, implemented on the FPGA/Zynq board, and tested successfully on a VGA monitor.

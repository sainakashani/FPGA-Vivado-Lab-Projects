# UART Protocol Implementation

## Overview
This project implements a UART communication module using Verilog/VHDL.  
The design was simulated in Xilinx Vivado, synthesized, and tested on an FPGA/Zynq board.

## Features
- UART transmitter
- UART receiver
- Serial data transmission
- Vivado simulation
- FPGA board validation

## Tools and Hardware
- Verilog / VHDL
- Xilinx Vivado
- FPGA / Zynq Board

## Results
The project was successfully simulated, synthesized, and tested on hardware.

# FPGA Vivado Lab Projects

This repository contains FPGA and digital design laboratory projects implemented during my Electrical Engineering studies at Sharif University of Technology.

The projects were developed using Verilog/VHDL, simulated and synthesized in Xilinx Vivado, and tested on FPGA/Zynq development boards.

## Projects

- VGA Display Controller
- UART Protocol Implementation
- PS-PL Communication through BRAM
- MicroSD Integration
- Interrupt Handling
- Signal Generation
- Zynq-Based Image Processing

## Tools and Hardware

- Verilog / VHDL
- Xilinx Vivado
- FPGA Board
- Zynq Development Board
- Board-level testing
- Simulation waveform analysis

## Notes

Each project includes source code, simulation files when available, constraints, and hardware test results.
